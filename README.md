# غيث — بورتفوليو تفاعلي

بورتفوليو عربي باتجاه RTL، مبني باستخدام **Laravel 12 / PHP 8.4، JavaScript، Bootstrap 5.3 وSQL**. تصميم داكن بألوان مريمية هادئة، حركات ظهور ومدارات تفاعلية، وتصميم متجاوب مع تفضيل تقليل الحركة.

## المزايا

- عرض المشاريع وتصفيتها حسب المجال، والمهارات والنبذة وروابط التواصل.
- لوحة تحكم `/admin`: إدارة المشاريع والمهارات، تعديل البيانات الشخصية، وقراءة الرسائل وحذفها.
- نشر المشاريع أو الاحتفاظ بها كمسودات، تمييزها وترتيبها.
- نموذج تواصل يحفظ الرسائل في قاعدة البيانات. لا يرسل بريدًا إلكترونيًا؛ تُقرأ الرسائل من لوحة التحكم.
- تسجيل دخول بجلسات آمنة، كلمات مرور مشفّرة، حماية CSRF، تحديد معدل الطلبات والتحقق من المدخلات.
- Bootstrap والخطوط محلية؛ لا يعتمد عرض الصفحة على CDN خارجي.

المشاريع والمهارات والنبذة الأولية **أمثلة قابلة للتعديل**، وليست أعمالًا أو خبرات موثقة. بيانات إنستغرام والهاتف مخصّصة حسب البيانات المقدّمة، ويمكن إضافة البريد الإلكتروني من لوحة التحكم. لا يُنشئ Seeder حسابًا بكلمة مرور افتراضية.

## التشغيل

المتطلبات: PHP **8.4+**، Composer 2، Node.js 22+ وnpm، وامتدادات PHP المعتادة لـLaravel مع `pdo_sqlite`, `mbstring`, `xml`, `dom`, `curl`, `fileinfo` و`zip`.

```bash
composer setup
php artisan portfolio:admin
composer dev
```

سكربت الإعداد يثبت الحزم من ملفات القفل، ينشئ `.env` والمفتاح عند الحاجة، ويجهز SQLite والمحتوى التجريبي والخطوط. تكراره يحافظ على المفتاح والبيانات المعدّلة. أدخل بريد المدير وكلمة مرور من 12 حرفًا على الأقل عند تشغيل أمر إنشاء الحساب؛ لا تحفظها في Git.

التطبيق يعمل على المنفذ `8000`، والدخول من `/login`. في البيئة السحابية الحالية أضف أولًا:

```bash
export PATH="/workspace/.tools/bin:$PATH"
cd /workspace/port
```

إذا منعت شبكة البيئة تنزيل أرشيفات GitHub، يمكن تثبيت حزم PHP عبر Git المهيأ:

```bash
bash scripts/setup.sh --prefer-source
```

## MySQL

SQLite هي قاعدة SQL الافتراضية لتسهيل التطوير. لاستخدام MySQL، ثبّت امتداد `pdo_mysql` وأنشئ قاعدة بيانات ومستخدمًا، ثم اضبط القيم الفعلية في `.env`:

```dotenv
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=portfolio
DB_USERNAME=portfolio
DB_PASSWORD=
```

أدخل كلمة المرور محليًا، ثم شغّل `php artisan config:clear` و`php artisan migrate --seed`. هذا ينشئ الجداول والمحتوى التجريبي في القاعدة الجديدة؛ نقل البيانات الموجودة من SQLite يتطلب تصديرها واستيرادها. تم اختبار SQLite في هذه البيئة، ولم يُشغّل خادم MySQL.

## الاختبارات

```bash
php artisan test
npm run build
```

اختبارات Laravel تستخدم SQLite في الذاكرة ولا تغير بيانات التطوير. تغطي الدخول، منع الوصول غير المصرح، إدارة المحتوى، تخزين الرسائل، التحقق من الروابط والحقول وتحديد الطلبات. شغّل `npm run test:browser` لاختبارات المتصفح. تستخدم قاعدة بيانات مؤقتة منفصلة وحساب اختبار مؤقتًا، ولا تعدّل بيانات التطوير. تتطلب Chromium (`/usr/bin/chromium` في هذه البيئة، أو حدّد `CHROMIUM_PATH`). تفاصيلها في `tests/browser/README.md`.

## النشر

اجعل مجلد `public/` هو جذر خادم الويب. استخدم HTTPS، و`APP_ENV=production` و`APP_DEBUG=false` و`SESSION_SECURE_COOKIE=true` و`APP_URL` الصحيح. احفظ `.env` وقاعدة البيانات والنسخ الاحتياطية خارج Git، وتأكد من صلاحيات الكتابة على `storage` و`bootstrap/cache`. شغّل `composer install --no-dev --optimize-autoloader` و`php artisan optimize` بعد ضبط البيئة. لا تستخدم خادم Artisan المخصص للتطوير للإنتاج.

لا توجد بيانات دخول افتراضية أو خدمة بريد أو نشر خارجي مضمنة. جميع الحسابات المنشأة بأمر `portfolio:admin` تمنح الوصول الكامل للوحة، ولا يوجد تسجيل عام للمستخدمين.
